# Sipasar-Ikan
SIPASAR NIAS adalah sistem informasi digital resmi yang menyajikan data ketersediaan stok, pembaruan harga komoditas harian, serta direktori lengkap pasar ikan dan pusat pelelangan hasil laut di berbagai wilayah strategis Kepulauan Nias, mulai dari Gunungsitoli, Nias Selatan, Nias Utara, hingga Nias Barat.
